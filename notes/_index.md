## 🎯 Core Frameworks Summary

### The Behavior Equation (Fogg)
```
B = M × A × P
Behavior = Motivation × Ability × Prompt
```

### Dual-Process Theory (Kahneman)
```
System 1 (Fast/Intuitive) + System 2 (Slow/Analytical)
```

### Memory Consolidation Cycle
```
Encoding → Consolidation → Retrieval
         ↑                    ↓
         ←←← (Spaced Repetition) ←←←
```

### Flow Channel Model
```
High Challenge + High Skill = FLOW
High Challenge + Low Skill = ANXIETY
Low Challenge + High Skill = BOREDOM
```

### Nudge Framework (EAST)
```
EASY + ATTRACTIVE + SOCIAL + TIMELY
```
